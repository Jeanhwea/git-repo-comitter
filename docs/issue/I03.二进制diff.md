# 二进制 diff 优化

## 背景

当前 `grc` 在获取 Git 差异时，对二进制文件（图片、PDF、编译产物等）会输出二进制 diff 内容，这些内容对 LLM 生成提交信息没有帮助且占用大量 token。

## 目标

过滤掉二进制文件的 diff 内容，只保留文件名列表和变更类型信息，在发送给 LLM 之前排除无效的二进制差异。

## 方案

1. 在 `git/diff.ts` 中解析 `git diff` 输出时识别二进制文件标记
2. 对二进制文件只保留 `diff --git a/X b/X` 行和 `Binary files a/X and b/X differ` 行
3. 去除中间的原始二进制内容
4. 在提交信息中注明二进制文件变更但不包含具体内容
